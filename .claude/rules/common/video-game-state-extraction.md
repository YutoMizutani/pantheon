# 動画から情報を読む — 一定間隔の間引きで「映っていない」と言わない

> 背景: 以前は frontmatter の `paths: **/*.mp4` で読み込む設定だったが、動画は ffmpeg で処理して Read しないため
> 一度も発動しなかった。また「密に＝fps 1〜2」と書いていたため、1 秒未満のホバー表示を毎回落としていた。
> 同じ取りこぼしで user に訂正されたことが複数回あり（ゲームの装備画面のホバー表示など）、条件なしの常時ルールに改めた。

<important if="動画（mp4/mov/mkv 等、user が渡した録画・Replay_*）や連続スクリーンショットから情報を読もうとしている、または動画について「映っていない／未確認」と書こうとしている">

## 原則

**間隔は時間で決めず、画面の変化で決める。** 一定間隔（fps=1 など）の間引きは、1 秒未満しか出ない表示
（ホバーのツールチップ、一瞬のダイアログ、数値の変化）を必ずどこかで落とす。一方で、全編を 0.1〜0.2 秒刻みで
目視するのは無駄。高くつくのは「画像を私が見ること」であって「フレームを取ること」ではないので、
取るのは細かく・見るのは文字認識と grep で絞ってから、にする。

## 手順

1. **全体の見取り図（粗い）**: `ffmpeg -vf "fps=N,scale=320:-1,tile=6x12"` 等の縮小一覧で、どこで何が起きているか
   （戦闘／メニュー／ホバー操作／暗転）を区間に分ける。ここは粗くてよい。**ここで「映っていない」とは言わない。**
2. **情報が出ている区間は、変化ベースで抽出する**:
   `python3 heaven/tools/video_states.py VIDEO --out DIR --ss <開始> --to <終了> --ocr`
   - 10fps で安く走査し、画面の一部が変わって次のフレームでも残っている瞬間（＝表示が出た／切り替わった）を全部残す。
     画面全体が動く区間は 2 秒に 1 枚、変化が無い区間は 5 秒に 1 枚。
   - 戦闘など動きの多い区間にはかけない（エフェクトで枚数が膨らむ）。メニュー・ホバー・結果画面の区間にかける。
3. **読むのは grep で当たった枚だけ**: `DIR/ocr.txt` を項目名・部位名・「装備条件」などで grep し、当たったフレームを
   原寸（必要なら切り抜きと拡大）で読む。名前・数値は文字認識と画像の 2 つで照合してから書く。
4. 小さい文字は 3〜5 倍に拡大して読む。切り抜き座標は縮小表示から目測せず、原寸に座標格子を描いて測ってから 1 回で切る。

## 「映っていない」と書いてよい条件

- 手順 2〜3 をその区間に実行し、grep でも目視でも見つからなかったときだけ。書くときは
  「◯◯区間を変化ベース抽出＋文字認識で確認した範囲では未検出」と方法を添える。
- 1 秒間隔・シーン検出・縮小一覧だけを見た段階の「映っていない」は禁止（それは自分の見た標本が粗いだけ）。
- サブエージェントが返す「映っていない／取得不能」も同じ扱い。親が手順 2〜3 で確かめ直すまで採用しない。

## 解像度の限界

ゲーム画面が小さく、拡大しても読めない場合は正直にそう言い、より良い元データ（全画面の撮り直し、セーブ・ログの直読み）を探す。
