# ツリー図の並び順 — ディレクトリが先、各群は `.` 始まりが先のアルファベット順

<important if="docs・README・CLAUDE.md などにディレクトリツリー図（├── / └── や字下げの一覧）を書く・書き換えようとしている">

- 同じ階層の中では **ディレクトリを先、ファイルを後** に並べる。
- ディレクトリ群・ファイル群それぞれの中は **`.` 始まりを先** にし、残りをアルファベット順（ASCII 順）に並べる。
  例: `.claude/` `.local/` `apps/` `context/` … `tools/` → `.gitignore` `CLAUDE.md`
- 1 行に複数の名前をまとめない（`skills/ commands/` のような行は 1 つずつに分ける）。

</important>
