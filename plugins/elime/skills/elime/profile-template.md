# elime の記録 — 雛形と仕組み

elime（Explain Like I'm Me）が解説の土台にする「user が知っていること」の記録の雛形。
手順の本体は同じフォルダの `SKILL.md`（プラグイン `elime`）。
記録の中身は環境ごとに育ち、プロジェクト root の `.local/elime-profile.md` に置く（gitignore するローカルの置き場）。

## 有効にする（opt-in）

`claude plugin marketplace add <この repo>` → `claude plugin install elime@pantheon`。
入れなければ何も働かない。初めて呼んだとき、記録が無ければ skill が projects と会話記録から作る。
止めるときはプラグインを外す。記録は `.local/elime-profile.md` を消せば消える。`.local/` ごと移植すれば記録も一緒に移る。

## 記録の雛形

```markdown
# elime の記録 — 私が知っていること

最終更新: <日付>

区分を分ける: 分ける
（分ける ＝ 学術・仕事の話は学術・仕事の分野で例える。分けない ＝ 区分を見ずに構造が一番合うもので例える。呼ぶときに「遊びで」「学術で」「区分なしで」と言えばその回だけ優先）

## 分野

| 分野・道具・遊び | 区分 | 深さ | 根拠（観測した場所・日付） |
|---|---|---|---|
| <例: Python> | 学術・仕事 | 使い込んでいる | <projects/foo・2026-10> |
| <例: 将棋> | 遊び | 触ったことがある | <elime で学んだ・2026-10-25> |

区分: 学術・仕事 ／ 遊び　深さ: 使い込んでいる ／ 触ったことがある

## まだ知らない（説明なしで使わない語）

- <語>

## 通じなかった比喩（写し先に使わない）

- <写し先> — <何の説明で・日付>

## 説明の好み

- <例: 短く。結論を先に。>

## 観測ログ（新しい順・1 行ずつ）

- <日付> <何を見て何を変えたか>
```
